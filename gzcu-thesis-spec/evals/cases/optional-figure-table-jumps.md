# Case: Optional Figure Table Jumps

## User Request

`检查这篇论文是否符合学校要求`

## Intent

Check that the skill does not incorrectly upgrade clickable figure/table jumps into a baseline submission hard requirement when the user only asks for general compliance.

## Expected Response Scope

- distinguish baseline submission requirements from optional final-docx enhancements
- keep figure/table numbering and in-text references as hard requirements
- keep clickable figure/table jumps as opt-in enhancement behavior
- mention that the compliant submission baseline proves bibliography jumping, not mandatory figure/table jumping
