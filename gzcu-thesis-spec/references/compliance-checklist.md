# Compliance Checklist

Use this file when reviewing an existing thesis or preparing a final submission checklist.

Classify each item as one of:

- `学校硬规则`
- `提交版基线建议`
- `人工复核项`

## 1. Writing and structure

- Chinese abstract is `400-600` words/characters.
- Chinese and English abstracts each have `3-5` keywords.
- TOC exists and matches the actual manuscript structure.
- Heading hierarchy follows chapter, second-level, and third-level numbering rules.
- Conclusion, references, and acknowledgements are present.
- The manuscript does not treat a sample-based 6-chapter structure as mandatory when the topic or school requirement differs.

## 2. Body formatting

- Level-1, level-2, and level-3 headings use the school document's font and size rules.
- Body text uses `小四` `宋体`.
- English and numeric text uses `Times New Roman`.
- Body line spacing is fixed `20 磅`.
- First-line indent is `2` Chinese characters.
- No heading is stranded as the last line of a page.

## 3. Figures and tables

- Every figure and table has a caption.
- Figure captions are below figures.
- Table captions are above tables.
- Figure and table numbering follows chapter numbering.
- Every figure and table is cited in the body.
- Tables spanning pages repeat the header and use `（续）` where needed.

## 4. References

- Reference entries follow the school formats.
- Reference numbering starts from `[1]`.
- The references list matches the order of first citation in the body.
- Journal `[J]` and monograph `[M]` entries include page ranges.
- Abstract does not cite references.

Clickable bibliography jumping is not a default compliance requirement in this simplified skill. If the user explicitly asks for Word automation enhancement, label it as an additional requirement rather than a school hard rule.

## 5. Conclusion and acknowledgements

- Conclusion format is compliant.
- Acknowledgements format is compliant.
- Acknowledgements include the supervisor's full name.

## 6. Sample-baseline checks

If the user wants alignment with the submitted sample `.docx`, additionally review:

- whether a 4-section model is used,
- whether abstract pages use Roman numerals,
- whether the TOC is separated from the main body,
- whether Chapter 1 starts Arabic numbering,
- whether odd/even header behavior is consistent,
- whether chapter starts are arranged on odd pages in the final layout.

These should be reported as `提交版基线建议` unless the school document independently confirms them.

## 7. Manual review items

- TOC field refresh in Word
- final pagination after edits
- odd-page chapter starts
- header visibility and header text
- page-number display
- figure/table page breaks
- cover and declaration page fidelity to school template

## 8. Review output order

Use this order when reporting:

1. `学校规则矩阵`
2. `不合规项`
3. `提交版基线偏差`
4. `人工复核项`
