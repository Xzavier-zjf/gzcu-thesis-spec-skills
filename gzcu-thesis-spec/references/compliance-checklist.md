# Compliance Checklist

Use this file for review mode, final audit mode, and delivery checklists.

This checklist distinguishes between:

- baseline submission requirements proven by the compliant `.docx`,
- optional final-docx enhancements,
- manual Word checks that AI cannot fully guarantee.

## 1. Writing-start checklist

Before drafting, confirm:

- real project repository or evidence is available,
- required chapter list is fixed or the compliant 6-chapter structure can be used,
- abstract length target is known,
- citation plan exists,
- figures and tables planned for each chapter are known,
- testing evidence and deployment evidence are available,
- Word finalization is in scope or explicitly out of scope.

## 2. Review checklist by severity

### Critical

- missing mandatory chapters or missing mandatory chapter substance,
- missing `本章小结`,
- abstract or conclusion contains citations,
- references are not cited in the body,
- citation order does not match the references list,
- Chapter 1, conclusion, references, or acknowledgements do not start on odd pages,
- Roman/Arabic page-number schemes are mixed incorrectly,
- references fewer than `12`,
- fewer than `2` English references,
- no concrete test cases or no result analysis,
- testing and deployment substance are both absent from the final structure.

### Major

- body uses first person,
- body is obviously colloquial,
- chapter shorter than `3` pages after final layout,
- missing figure/table in-text references,
- long raw code pasted into the body,
- journal `[J]` or monograph `[M]` without page ranges,
- TOC not generated by Word,
- section, page-number, or header logic is inconsistent with the 4-section template-compatible model,
- body citations remain plain-text numbers in the final `.docx` when clickable reference jumping is required,
- bibliography cross-references lose superscript formatting.

### Minor

- heading spacing inconsistent,
- caption placement inconsistent,
- English/numeric font not in `Times New Roman`,
- table borders or continuation marks inconsistent with the template-compatible style,
- acknowledgements missing the supervisor's full name,
- figure/table cross-references are not implemented even though the user explicitly requested clickable figure/table jumping.

## 3. Manual-review items

Always call out items that require human confirmation in Word:

- whether a chapter truly starts on an odd page after all pagination shifts,
- whether a blank transition page is needed or already present,
- whether TOC fields were refreshed after heading changes,
- whether the abstract section starts at Roman `I`,
- whether the TOC section hides page numbers correctly,
- whether odd-page headers correctly follow the current level-1 heading,
- whether table continuation pages repeat headers correctly,
- whether captions wrap cleanly after manual image resizing,
- whether body reference cross-references really jump to the intended bibliography entries with `Ctrl + 点击`,
- whether optional figure/table cross-references really jump to the intended captions when the user asked for them,
- whether optional body figure/table cross-references still match正文小四 (`12.0` pt) rather than caption五号,
- whether code screenshots really use a white background,
- whether the supervisor's full name is correct,
- whether page counts satisfy `每章不少于3页` after final layout.

## 4. Output template for review mode

Use this reporting order:

1. `Findings`
2. `Rule coverage`
3. `Manual checks`
4. `Open risks`

Under `Findings`, tie each issue to a concrete school rule or compliant-template rule.

## 5. Final delivery audit

Before final delivery, confirm:

- cover and explanation pages stayed unchanged,
- formatting rules started from the Chinese abstract page,
- sections match the template-compatible 4-part model,
- abstract pages use Roman numerals,
- TOC page numbers remain hidden,
- Chapter 1 starts Arabic numbering at `1`,
- conclusion, references, and acknowledgements continue Arabic numbering,
- every chapter starts on an odd page,
- even-page header is `广州城市理工学院本科毕业设计（论文）`,
- odd-page header follows the current level-1 heading rather than a manually hard-coded label,
- headings and body text stay compatible with the compliant template,
- every reference is cited in the body and ordered correctly,
- no citations appear in the abstract, chapter summaries, or conclusion,
- figures/tables are cited and numbered by chapter,
- body citations are Word cross-references when final clickable jumping is required,
- bibliography cross-references still appear as superscript,
- figure/table clickable cross-references are only treated as required when the user explicitly asked for them,
- the manuscript still needs or does not need any manual Word cleanup.
