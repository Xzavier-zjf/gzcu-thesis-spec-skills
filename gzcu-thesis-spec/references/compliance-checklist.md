# Compliance Checklist

Use this file for review mode, final audit mode, and delivery checklists.

## 1. Writing-start checklist

Before drafting, confirm:

- real project repository or evidence is available,
- required chapter list is fixed,
- abstract length target is known,
- citation plan exists,
- figures and tables planned for each chapter are known,
- testing evidence and deployment evidence are available,
- Word finalization is in scope or explicitly out of scope.

## 2. Review checklist by severity

### Critical

- missing mandatory chapters,
- missing `本章小结`,
- abstract or conclusion contains citations,
- references are not cited in the body,
- citation order does not match the references list,
- conclusion, references, or acknowledgements do not start on a new page,
- chapter does not start on an odd page,
- references fewer than `12`,
- fewer than `2` English references,
- no concrete test cases or no result analysis.

### Major

- body uses first person,
- body is obviously colloquial,
- chapter shorter than `3` pages,
- missing figure/table in-text references,
- figure captions exist but body figure references are left as plain text instead of Word cross-references when clickable jumping is required,
- table captions exist but body table references are left as plain text instead of Word cross-references when clickable jumping is required,
- body figure/table cross-references drift to caption font size instead of staying at body text size,
- long raw code pasted into the body,
- journal `[J]` or monograph `[M]` without page ranges,
- TOC not generated by Word,
- page-number or header sections mixed together incorrectly,
- bibliography cross-references lose superscript formatting.

### Minor

- heading spacing inconsistent,
- caption placement inconsistent,
- English/numeric font not in `Times New Roman`,
- table borders or continuation marks inconsistent,
- acknowledgements missing the supervisor's full name.

## 3. Manual-review items

Always call out items that require human confirmation in Word:

- whether a chapter truly starts on an odd page after all pagination shifts,
- whether a blank transition page is needed or already present,
- whether TOC fields were refreshed after heading changes,
- whether table continuation pages repeat headers correctly,
- whether captions wrap cleanly after manual image resizing,
- whether figure references really jump to the intended captions with `Ctrl + 点击`,
- whether table references really jump to the intended captions with `Ctrl + 点击`,
- whether body figure/table cross-references still match正文小四 (`12.0` pt) rather than caption五号,
- whether code screenshots really use a white background,
- whether the supervisor's full name is correct,
- whether page counts satisfy `每章不少于3页` after final layout.

## 4. Output template for review mode

Use this reporting order:

1. `Findings`
2. `Rule coverage`
3. `Manual checks`
4. `Open risks`

Under `Findings`, tie each issue to a concrete school rule.

## 5. Final delivery audit

Before final delivery, confirm:

- cover and explanation pages stayed unchanged,
- formatting rules started from the Chinese abstract page,
- header visibility matches the school rule by section,
- Roman and Arabic page numbers are correct,
- references and acknowledgements continue Arabic numbering,
- every chapter starts on an odd page,
- headings, body text, references, and acknowledgements use the required sizes,
- every reference is cited in the body and ordered correctly,
- no citations appear in the abstract, chapter summaries, or conclusion,
- figures/tables are cited and numbered by chapter,
- figure references use clickable Word cross-references when the final `.docx` requires jump support,
- table references use clickable Word cross-references when the final `.docx` requires jump support,
- figure and table cross-references still display at body text size `小四` (`12.0` pt),
- bibliography cross-references still appear as superscript,
- the manuscript still needs or does not need any manual Word cleanup.
